# DevMentors

> Transformando o futuro, uma geração por vez.

DevMentors é uma plataforma educacional que capacita jovens com habilidades técnicas (hard skills) e interpessoais (soft skills), preparando-os para os desafios do mercado de tecnologia.

## Sobre o DevMentors

O DevMentors nasceu em 2022 com a missão de transformar a educação em tecnologia. Nosso foco vai além de apenas ensinar a programar: ajudamos você a desenvolver **liderança**, **comunicação** e **trabalho em equipe**, preparando profissionais completos e prontos para brilhar no mercado.

### Nossa Missão

Capacitar jovens talentos com as habilidades necessárias para ter sucesso em suas carreiras de desenvolvimento, combinando conhecimento técnico com desenvolvimento pessoal.

### Nossos Valores

- **Educação de Qualidade**: Aprendizado prático com mentores experientes
- **Desenvolvimento Integral**: Hard skills + soft skills
- **Comunidade**: Ciclo contínuo de aprendizado e mentoria
- **Oportunidade**: Igualdade de acesso ao conhecimento

## Como Funciona

No DevMentors, você aprende **fazendo**! Nossa abordagem é centrada em projetos reais:

### Metodologia

1. **Treinamentos Práticos**: Trabalhe com tecnologias reais em projetos concretos
2. **Mentoria Personalizada**: Receba orientação de desenvolvedores experientes
3. **Desenvolvimento de Soft Skills**: Desenvolva liderança, comunicação e trabalho em equipe
4. **Ciclo de Crescimento**: Quem se destaca vira mentor e ajuda a próxima geração

### Tecnologias Utilizadas

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP, Laravel
- **Outras**: Metodologias ágeis, versionamento com Git

## Começando

### Pré-requisitos

- Conhecimento básico de programação (não obrigatório)
- Vontade de aprender e crescer
- Computador com acesso à internet
